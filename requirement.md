## requirements.txt

```txt
Flask==3.0.0
```
`Flask==3.0.0` em `requirements.txt` informa ao `pip` que o projeto depende do Flask na versão 3.0.0. O `==` fixa a versão, para que a instalação use essa versão específica.

Para instalar as dependências listadas no arquivo, execute:
## Terminal

```cmd
pip install -r requirements.txt
```
