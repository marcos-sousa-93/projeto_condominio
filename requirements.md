# Diretório: D:\gestao-condominio\
##  requirements.txt
```txt
Flask==3.0.0
```
Esse arquivo lista as dependências do projeto.
A linha especifica que ele usa o Flask na versão 3.0.0. 

```txt
Werkzeug==3.0.1
```
Werkzeug é uma biblioteca usada pelo Flask para funções do servidor web, como tratar requisições e respostas HTTP. 
O `==3.0.1` fixa a dependência nessa versão específica quando o projeto instala os pacotes com `pip install -r requirements.txt`.

Para instalar essa versão, execute no terminal, dentro da pasta do projeto:
```cmd
pip install -r requirements.txt
```
